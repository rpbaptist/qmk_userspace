**Active effect** — The RGB effect shown while the user types.
**Idle effect** — The RGB effect shown after the idle timeout passes with no key press. _Avoid:_ passive effect.
**Current effect** — The RGB effect the keyboard shows now. With idle animation on, it is the active effect or the idle effect.
**Idle animation** — The setting that switches the current effect to the idle effect after the idle timeout, and back to the active effect on a key press.
**Idle timeout** — The time with no key press before idle animation shows the idle effect.
**Profile** — A named set of active effect, idle effect and idle timeout: typing or gaming. _Avoid:_ mode.
**Layer indicator** — Underglow color that shows the highest active layer. It is hidden while the idle effect shows.
